# 硬件设计资料

本目录保存整机硬件相关资料，包括结构设计、PCB 工程和物料清单。

## 目录说明

- `mechanical/`：外壳、面板等机械结构文件。
- `bom.CSV`：物料清单。
- `pcb/`：预留用于原理图、PCB 源文件、Gerber、坐标文件和制造资料；当前尚未提交。

## 维护要求

- 建议将 `bom.CSV` 统一更名为 `bom.csv`，保证跨平台一致性。
- PCB 文件应保留可编辑工程源文件，并按版本建立发布包。
- 不要在 BOM 中加入供应商账号、报价单或个人联系方式。

## 硬件组成与版本管理

当前 BOM 涵盖 SC171 V2 边缘平台、STM32 舵机控制板、近红外摄像头与补光、MG90S 双轴云台、电源模块和防水结构件。具体数量、规格和采购信息以 `bom.CSV` 为准。

`pcb/` 后续应包含可编辑工程、Gerber、贴片坐标、原理图 PDF、装配图及版本说明。结构、PCB 和 BOM 应使用同一硬件版本号；涉及接口、供电、孔位或器件替换时必须同步更新三者。

## 使用与验收流程

装机前先根据 BOM 清点主控、控制板、摄像头、补光、云台、电池和转换模块，确认型号与接口方向。随后按照结构图固定主板、镜头和云台，先完成不带负载的供电测试，再连接摄像头、串口控制板和舵机。供电测试应记录输入电压、空载电流和舵机动作时的最低电压；若边缘板在云台动作时重启，应优先检查电源余量、地线共地和 DC-DC 模块，而不是修改软件参数。

硬件验收可按“供电—串口—摄像头—云台—整机散热”的顺序进行：确认设备稳定启动后，用串口工具检查控制板响应，再在边缘端查看摄像头帧率与分辨率，最后以小范围角度命令验证水平和俯仰方向。结构更新后需要重新检查线束拉力、镜头视场、散热路径、重心与防水密封。任何未经验证的器件替换都应记录在 BOM 变更中，并保留旧版资料以便回滚。
