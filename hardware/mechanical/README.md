# 机械结构文件

本目录包含设备外壳和控制面板等三维/二维结构设计文件。

## 当前内容

- `外壳.stp`：外壳三维交换模型。
- `电池仓开关面板.dwg`：电池仓开关面板二维图纸。

## 使用说明

使用支持 STEP、DWG 格式的 CAD 工具查看或编辑。提交更新时应说明适配的硬件版本、材料、尺寸或孔位变更；导出的图片和 PDF 应与源文件一起保留。

## 装配与交付

- 外壳应为 SC171 主板、摄像头、红外补光、电池与云台预留固定、走线和散热空间。
- 电池仓开关面板的孔位、开关规格和线束方向应与 BOM 一致。
- 发布结构版本时，同时提供 STEP、二维工程图、装配爆炸图、预览图和变更说明；不要只提交截图。

## 查看与修改流程

查看 `外壳.stp` 时，先确认模型单位为毫米，并检查外形尺寸、安装孔、镜头窗口、电池仓和散热开口是否与当前硬件版本匹配。打开 `电池仓开关面板.dwg` 时，应核对开关开孔、面板厚度、固定孔和线束出口位置。若使用不同 CAD 软件导入文件，应将导入后的模型与原始尺寸进行抽检，避免单位转换导致孔位或壳体比例错误。

修改结构前，建议建立新的版本目录或在提交说明中记录版本号、修改目的、受影响部件和验证结果。修改镜头、补光或云台安装位置后，必须重新确认视场是否被外壳遮挡、线束是否会随云台运动拉扯、重心是否偏移以及散热是否受影响。输出给加工方的资料至少包括二维尺寸图、材料与表面处理说明、关键公差、螺丝规格和装配顺序。若结构图中包含设备序列号、人员姓名、客户标识或现场照片，应在对外导出前移除。
