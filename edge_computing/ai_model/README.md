# AI 模型资源

集中管理模型训练工程、权重、评测材料和部署转换资源。

## 当前内容

- `cyclegan/`：跨模态图像转换相关训练与推理代码。
- `facenet/`：人脸特征提取、训练与验证相关资源。

## 模型生命周期

```text
授权数据 → 训练/微调 → 离线评测 → 导出模型 → 目标设备验证 → 版本化发布
```

训练与部署必须区分：训练工程可以包含代码与配置模板；部署包只包含必要的模型、推理适配代码和校验信息，不能携带训练集、抓拍结果或人脸特征库。

## 当前工程提示

- `cyclegan/` 含训练、测试、数据集与 checkpoint 目录，提交前应检查数据集和权重是否具备再分发授权。
- `facenet/` 含 LFW 评测、模型数据和 AdaFace 相关代码；应在模型卡中区分第三方资源与自研部分。

模型发布至少应说明：名称、版本、来源、许可证、输入/输出、评测集、设备运行时、量化方式、SHA-256、已知限制和回滚版本。

## 使用方法与验证

训练模型前，先确认训练数据已经获得授权，并将原始数据存放在受控位置，而不是直接提交到仓库。CycleGAN 工程用于处理近红外与可见光图像之间的转换，FaceNet/AdaFace 资源用于生成人脸特征和执行验证；两类模型的输出尺度、预处理方式和输入尺寸必须在串联前明确。训练完成后，应在隔离的评测集上记录准确率、误识率、漏识率、远距离和弱光场景表现，不能只使用训练集结果。

准备部署时，导出目标运行时所需的模型格式，并通过工具目录完成 ONNX/TFLite 转换或量化。转换后先比较少量样本的输入输出维度和数值误差，再到目标设备上测量首次加载时间、单帧耗时、内存占用和稳定性。发布包中保留模型卡、校验和和回滚说明；模型文件与代码必须能对应到同一版本。若模型表现下降，优先回滚到已验证版本并保留问题场景，不要直接覆盖旧权重。
