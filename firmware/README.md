# 设备底层固件

存放传感器、执行器和控制板的底层固件工程。

## 当前模块

- `mg90s舵机控制/`：基于 STM32 的 MG90S 双轴舵机控制工程。

## 模块职责

底层固件接收上位机或边缘端的控制指令，完成舵机 PWM 驱动、串口通信、状态指示和必要的安全复位。视觉算法应通过稳定的串口协议与该层通信，而不是直接依赖寄存器或引脚。

## 推荐开发流程

1. 打开目标工程并确认 MCU 型号、时钟和下载器配置。
2. 使用串口工具验证命令收发，再连接云台进行低速、限位测试。
3. 记录命令格式、波特率、供电范围、默认姿态和异常处理策略。
4. 排除编译输出、IDE 缓存和设备私有配置。

## 使用与联调

固件开发应从独立板级测试开始。先在不接舵机负载的情况下烧录程序并打开串口监视器，确认启动信息、波特率和命令回显正常；再接入一个舵机，观察方向、零位和抖动情况，最后接入双轴云台。边缘端程序调用云台前，应先确认两端使用相同的串口号、波特率、命令格式和坐标系定义。水平、俯仰方向相反时优先在协议层或配置层处理，不应直接修改底层定时器逻辑。

出现控制不稳定时，按以下顺序排查：检查舵机供电是否跌落；确认 USB 转串口的 TX/RX 是否交叉并共地；查看是否存在多个程序同时占用串口；将自动追踪关闭后发送固定角度命令；最后才检查 PWM 周期、限位参数和控制算法。发布固件时，应写明编译器版本、目标芯片、下载器、烧录步骤、默认通信参数和已知限制。烧录包与源代码必须可追溯到同一版本，且不能包含设备的私有串口配置或现场调试日志。
