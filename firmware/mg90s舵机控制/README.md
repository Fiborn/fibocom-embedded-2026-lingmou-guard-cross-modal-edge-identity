# MG90S 舵机控制固件

本工程用于 STM32 控制 MG90S 舵机，向上层人脸跟踪或云台控制逻辑提供执行能力。

## 工程结构

- `USER/`：应用入口、Keil 工程和中断配置。
- `HARDWARE/`：舵机、按键、LED 等硬件驱动。
- `SYSTEM/`：延时、串口和系统配置。
- `STM32F10x_FWLib/`、`CORE/`：STM32F10x 固件库与启动文件。

## 构建与烧录

使用 Keil MDK 打开 `USER/USART.uvprojx`，根据实际硬件核对目标芯片、时钟和串口参数后编译烧录。`OBJ/` 是构建输出，不应作为源代码维护对象。

## 串口与供电注意事项

- 工程说明中使用 USART1，默认通信参数为 `115200` 波特率；接线和电平须在烧录前确认。
- 舵机电源应与控制板电源规划分开评估，避免云台动作造成 MCU 复位。
- 首次联调应关闭自动跟踪，以小角度、低速命令确认旋转方向与机械限位。

建议后续补充上位机命令表、帧格式、校验方式、水平/俯仰角范围和故障码，作为边缘端舵机控制接口契约。

## 具体操作步骤

1. 在 Windows 开发机安装 Keil MDK，并使用 `USER/USART.uvprojx` 打开工程。
2. 在 Target 配置中核对 STM32F103 器件、下载器类型和系统时钟；不要直接沿用未知来源的下载配置。
3. 编译成功后连接 ST-Link 或项目规定的下载器，先在无舵机负载状态下下载并复位。
4. 使用 USB 转串口模块连接 USART1，打开串口工具并设置为 `115200`，确认板卡能够输出或回显测试信息。
5. 接入单个 MG90S 舵机后发送小角度控制命令，确认方向、零位、速度和机械限位；通过后再安装双轴云台。

## 验证与故障处理

舵机不动作时，先用万用表确认独立供电和共地，再检查信号线、串口收发线与命令格式。舵机持续抖动通常与供电纹波、机械卡滞、死区设置或控制频率有关；MCU 重启则优先检查电流峰值和降压模块。每次修改控制参数都应记录初始值、修改值、测试角度和结果。`OBJ/`、`.axf`、`.hex` 等构建产物可用于现场烧录，但不应替代可重复构建的源代码和工程文件。
