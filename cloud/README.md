# 云端平台服务

本目录包含设备接入、数据转发、远程管理和用户可视化相关服务。

## 目录说明

- `iot_platform/`：设备通信与后端服务。
- `web_frontend/`：Web 与移动端可视化页面。

## 服务边界

云端应负责设备连接管理、事件中转、访问控制、告警展示和配置下发，不应默认保存完整视频流、人脸裁剪图或生物特征向量。确需保存时，应明确保存期限、访问权限、加密与审计策略。

## 推荐部署顺序

1. 配置后端运行环境、持久化服务和最小权限账号。
2. 设置 HTTPS/WSS、反向代理、日志轮转和备份策略。
3. 部署后端通信服务，使用测试设备验证认证和重连。
4. 构建前端，注入测试或生产环境的 API 配置。
5. 仅在授权的测试样本上进行端到端验收。

## 日常使用流程

设备接入前，为每台边缘设备分配独立身份与最小权限，并在后台登记设备版本、部署位置和负责人信息；这些资料应保存在受控配置系统中，不应写入仓库。设备上线后，前端可用于查看连接状态、接收经过脱敏的识别事件、管理授权的人脸库任务和查询运行指标。测试阶段先验证设备断网、重连、认证失败、消息过大和服务重启等异常路径，确认系统不会泄露原始图像或无限累积待发消息。

运行维护时，需要定期检查服务日志、磁盘空间、容器状态、证书有效期和备份任务。告警服务应设置冷却时间和幂等标识，避免同一目标在短时间内重复推送。若业务要求保留事件，建议只保存必要的时间、设备、规则和脱敏结果，并按制度设定自动清理期限。任何增加数据采集范围、接入第三方平台或导出用户数据的变更，均应先完成隐私、安全和权限评审。
